# Music

网易云音乐解析工具，部署在 Cloudflare Pages。

## 文件结构

```
public/
├── index.html          # HTML 结构
├── css/style.css       # 样式
├── js/
│   ├── md5.js          # MD5 实现
│   ├── utils.js        # 工具函数
│   ├── api.js          # API 认证与请求
│   ├── local-library.js # 本地曲库：扫描/匹配/直写文件夹
│   └── app.js          # UI 交互与下载逻辑
```

## 使用

站点是纯静态的，运行时不需要 Node；Node 只用于本地开发服务器和部署。

```bash
npm install      # 只装 wrangler（已配置 npmmirror 镜像，见 .npmrc）
npm run dev      # 本地开发 http://localhost:9001
npm run deploy   # 部署到 Cloudflare Pages
```

不装依赖也可以直接用任意静态服务器托管 `public/`（File System Access API 需要 https 或 localhost）。

## 本地曲库与去重

下载前可以先「选择音乐文件夹」（Chrome / Edge 的文件系统访问 API）：

- 递归扫描该文件夹（最深 4 层），按网易云标准文件名 `歌手1,歌手2 - 标题.扩展名` 建索引
- 忽略 `.lrc` 歌词和 `desktop.ini`；`.ncm` 也计入已下载
- 匹配前会归一化：全角/半角、大小写、多余空白，以及歌手分隔符（本地文件的 `,` `&` 对上接口返回的 `/`），并忽略浏览器自动追加的 ` (1)` 重复后缀
- 严格模式按「歌手 + 歌名」判定，宽松模式只按歌名（翻唱/同名曲会被误判为已下载，默认关闭）
- 命中的歌曲默认不勾选、不请求接口，因此跳过它们同样能避免触发上游限流
- 文件夹句柄存在 IndexedDB 里，下次进入页面自动复用，权限失效时点一次「选择音乐文件夹」重新授权即可

拿到写权限后文件用 `createWritable()` 直接流式写入该文件夹，不再堆到浏览器下载目录；同名时自动追加 ` (n)` 且不覆盖已有文件。下载过程中出现无权限、跨域或写入失败，该首自动退回浏览器下载，整批不中断。

## 批量下载

- 列表可按歌名/歌手/专辑搜索，可「隐藏已下载」，也可逐首勾选；默认选中的就是「本地没有 + 歌单内不重复」的部分
- 保留原有的下载间隔设置（用于规避接口限流），新增「停止」按钮
- 结束后汇总写入文件夹 / 浏览器下载 / 无下载地址 / 失败的数量

## 说明

- 前端内置多个音乐 API 候选源，启动时会检查可用性，可手动选择当前使用的接口
- 下载逻辑在前端完成：优先写入已授权的本地文件夹，其次 Blob 下载，跨域失败时退回直接链接下载
